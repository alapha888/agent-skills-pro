What's inside

multi-agent-decompose
Split a complex goal into subtasks for parallel agent execution: dependency ordering, a per-subtask contract (input, output, success criteria), and a result-merging protocol that never resolves conflicts by guessing.
codebase-map
Build a one-page map of an unfamiliar repository — entry points, module boundaries, one traced primary flow, key files — so an agent or developer can navigate it without reading everything.
release-notes
Generate user-facing release notes from git history between two refs: categorized changelog (Added / Fixed / Changed / Breaking) in keep-a-changelog style, with breaking changes impossible to miss.
