# Agent Skills Pro

Three advanced agent skills for the work that comes after the basics. A paid companion to the [free Agent Skills pack](https://github.com/alapha888/agent-skills-en) (MIT, 5 skills) — the free pack stays free; Pro covers the advanced workflows.

## Skills

| Skill | What it does |
|---|---|
| `multi-agent-decompose` | Splits a complex goal into subtasks for parallel agent execution: dependency ordering, per-subtask contracts, and a result-merging protocol. |
| `codebase-map` | Builds a one-page map of an unfamiliar repo: entry points, module boundaries, one traced primary flow, key files. |
| `release-notes` | Generates user-facing release notes from git history between two refs, keep-a-changelog style, with breaking changes impossible to miss. |

## How to use

Each skill lives in `skills/<name>/SKILL.md`. The file starts with `name` and `description` frontmatter so agent frameworks can surface it, followed by a step-by-step workflow, rules, a runnable example, and anti-patterns. Point your agent at the `SKILL.md` (Claude Code, Codex CLI, or any framework that reads skill files).

## Design principles

Same as the free pack: checklists, not essays; no fabrication (missing info is marked, never guessed); actionable over exhaustive. These are workflow guides, not software — they give your agent a repeatable checklist for three specific jobs.
